# Medisense 介面設計文件（2026-10-28）

以「新對話」頁為基準，其他頁面之後都照這份規範改。實作位置：`frontend/src/radius.css`、`recents.css`、`admin-home.css`、`welcome.css`、`chat-type.css`。

## 1. 設計原則
- 參考 ChatGPT、Amazon Quick、Gemini Enterprise：緊湊、安靜、少留白、字體小。
- 側邊欄與頁面同一個底色，只用一條淡細線分隔，不用漸層或陰影。
- 任何「展開項」（選單、子選單）由我們自己保證位置正確，不留給使用者檢查。

## 2. 視覺規範
| 項目 | 規範 |
|---|---|
| 底色 | 側邊欄與頁面同為 `#FCFCFC`；分隔線 1px、約 4.5% 黑 |
| 字體 | 系統字體（SF / PingFang）；Plus Jakarta Sans 只用於 logo |
| 字級 | 內文 14px；選單 13–14.5px；說明文字 11–12px 灰（`#7b828d` / `#9a9ca3`）；歡迎詞 24px 正常字重 |
| 圓角 | 按鈕膠囊形；控制項 10px；卡片 14px；彈出選單／對話框 16–24px；輸入框 28px |
| hover | 小控制項用淡綠 `#f3fcf8`；卡片與列表不用；側邊欄的列用中性灰 `rgba(0,0,0,.05)` |
| 強調色 | 綠 `#1f8656`（選中、連結） |
| 選單 | 白底、無邊框、柔和陰影；列高 34–38px；圖示＋文字；勾選在右；刪除紅色；分隔線 1px `#e8e9ec` |
| 區塊標題 | 13px 灰字，可收合者帶小箭頭 |
| 首頁類頁面 | 不使用 tab；用分組卡片（圖示方塊＋標題＋一行灰色說明） |

## 3. 版面
- **側邊欄**：預設 288px，可拖曳調寬（232–480px，記在瀏覽器；連點兩下還原）；左右留白 8px；列高 36px、內距 10px；收合後只剩 icon，連續一列、無分組標題與間隙。
- **選單展開方向**：預設往下，空間不足才往上；一律經 `frontend/src/fitMenu.js`，確保不超出視窗。
- **新對話頁**：水母動畫與歡迎詞同時開始；歡迎詞每次隨機一句、不連續重複（清單在 `App.jsx` 的 `GREETINGS`）。

## 4. 輸入框選單
- **+ 選單**：寬 228px、列高 34px；連接器子面板顯示各連接器狀態（已連接✓／連接），底部固定「查看全部」；語音語言往上展開。
- **資料範圍**：標題＋灰色說明，勾選在左，選中標題為綠色。
- **模型**：Auto 在最上（附一行說明）、其餘為「圖示＋名稱」；無搜尋框；底部提示 9px 灰字，兩行內。
- **Agent**：蓋在輸入框上，上緣與輸入框齊平，從 Agent 按鈕右側往右展開，右緣對齊輸入框。
- **貼上圖片**：可貼上、拖入或從 + 選單選取；縮圖顯示於輸入框，送出後顯示在訊息上方。

## 5. 側邊欄功能
- **專案**（可收合）與**最近項目**（可收合），含篩選（全部／今天／7 天／30 天／已封存）與排序（更新／建立時間）。
- **對話 ⋯ 選單**：重新命名、釘選、鎖定對話、分享（暫時停用）、封存、刪除、移至專案。
  - 鎖定＝唯讀：不能送訊息、改名、移動、封存或刪除，需先解除。
  - 分享待決定權限規則（見第 9 節）。
- **專案頁**：名稱、重新命名、刪除專案（對話不會被刪）、在專案內開新對話；專案內的對話在聊天區左上角顯示資料夾與專案名。
- 預設首頁為「新對話」。

## 6. 管理帳戶
- 首頁改為分組卡片（模型／治理），無 tab、無麵包屑；側邊欄頂端的無作用標題已移除。
- **模型**：改成「可選模型」目錄，點「註冊」後再「套用到 LiteLLM」即可使用；已移除「已核准的雲端供應商」機制。目錄清單在 `backend/app/engine/model_catalog.py`。

## 7. 資料安全（與介面相關的決定）
- 任何模型看到之前，文字與圖片都先去識別化／遮蔽；無關閉開關，失敗即拒絕（fail closed）。
- 圖片：用 Sensitive Data Protection 把圖中所有文字塗黑（預設），只保存塗黑後的版本；不偵測臉部與手寫；「僅院內模型」下不支援圖片；每個對話最多 3 張。
- 對話保存 180 天、回饋 365 天（Firestore TTL）；圖片隨對話刪除，並有儲存空間到期規則。
- 網路搜尋、語音輸入預設關閉，由管理員開關控制。

## 8. 工程注意事項
- 堆疊式 PR 請由最上層往下依序合併，或一開始就把 base 設為 `main`，避免工作沒進主線。
- 後端變更（專案、釘選／鎖定／封存、模型目錄、圖片）需要手動部署後端；圖片到期規則需再跑一次 `infra/11-retention-ttl.sh`。
